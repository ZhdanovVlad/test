



# Запуск

Требуется Node.js 18 или новее.

bash
npm test


Для запуска только одного файла:

bash
node --test test/orderCalculator.test.js


# Что проверяется

- расчёт стоимости одного и нескольких товаров;
- пустая корзина;
- количество товара больше одного;
- промокод STUDENT10;
- промокод NODE20 и его граничные значения;
- неизвестный промокод;
- курьерская доставка;
- бесплатная доставка от 3000 рублей;
- самовывоз;
- отрицательная цена;
- нулевое и дробное количество;
- неизвестный способ доставки;
- итоговая стоимость заказа;
- асинхронное оформление заказа;
- mock-объект платёжного сервиса;
- корректная обработка ошибки платежа.

В тестах используется встроенный модуль `node:test`, поэтому дополнительные зависимости устанавливать не требуется.

# Пример заказа

```js
const order = {
  items: [
    { name: 'Клавиатура', price: 2500, quantity: 1 },
    { name: 'Кабель', price: 500, quantity: 2 }
  ],
  promoCode: 'STUDENT10',
  deliveryType: 'courier'
};
```

Для этого заказа стоимость товаров равна 3500 рублей, после скидки STUDENT10 — 3150 рублей. Курьерская доставка становится бесплатной только при сумме после скидки от 3000 рублей, поэтому итог составляет 3150 рублей.

# Подход к тестированию

Тесты построены по схеме Arrange–Act–Assert:
1. Arrange — подготовка входных данных;
2. Act — вызов тестируемой функции;
3. Assert — проверка результата.

Для однотипных проверок стоимости используется параметризованный набор тестовых случаев.
